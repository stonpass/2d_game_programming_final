# 2d_game_programming_final

2D게임프로그래밍 기말 프로젝트로 제작한 Godot 기반 2D RTS 게임입니다.

## 실행 파일

빌드된 실행 파일은 아래 위치에 있습니다.

```text
build/KMURTS.exe
```

실행 시 같은 폴더의 `KMURTS.pck` 파일이 함께 필요하므로, `build/` 폴더 안의 두 파일을 같은 위치에 둔 상태로 실행해야 합니다.

## 프로젝트 개요

- 엔진: Godot Engine 4.6
- 언어: GDScript
- 장르: 2D RTS
- 주요 기능: 유닛 선택, 이동 명령, 자원 채집, 건물 건설, 유닛 생산, 미니맵, UI 명령 패널

## Godot에서 실행하는 방법

1. Godot Engine 4.6에서 프로젝트 폴더를 엽니다.
2. `project.godot`을 선택합니다.
3. 실행 버튼을 눌러 게임을 시작합니다.

## 참고

`build/KMURTS.exe`는 용량이 커서 Git LFS로 관리합니다.
