# 계명크래프트

2D게임프로그래밍 기말 프로젝트로 제작한 Godot 기반 2D RTS 게임입니다.

## 프로젝트 개요

- 엔진: Godot Engine 4.6
- 언어: GDScript
- 장르: 2D RTS
- 주요 기능: 유닛 선택, 이동 명령, 자원 채집, 건물 건설, 유닛 생산, 미니맵, UI 명령 패널

## 실행 방법

1. Godot Engine 4.6에서 프로젝트 폴더를 엽니다.
2. `project.godot`을 선택합니다.
3. 실행 버튼을 눌러 게임을 시작합니다.

## 참고

GitHub 저장소에는 프로젝트 소스와 에셋을 중심으로 포함하며, 로컬 빌드 결과물과 보고서 검토용 문서는 제외했습니다.
